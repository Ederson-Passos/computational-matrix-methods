\section{Results and Discussion}

\subsection{Problem 1: Cholesky Factorization and Linear System}

The prescribed matrix $A \in \mathbb{R}^{10 \times 10}$ is symmetric by construction. Furthermore, it is strictly positive definite. The algorithmic assembly defines $A = B B^T + 10 I$. For any non-zero vector $x \in \mathbb{R}^{10}$, the quadratic form is bounded strictly away from zero:
\begin{equation}
    x^T A x = x^T (B B^T + 10 I) x = \|B^T x\|_2^2 + 10 \|x\|_2^2 > 0.
\end{equation}
Consequently, $A$ is symmetric positive definite (SPD), guaranteeing the existence and uniqueness of the Cholesky factorization $A = G G^T$.

The numerical computation of the lower triangular Cholesky factor $G$ yields:

\end{figure}
\begin{equation}

Since $A$ is SPD, the $2$-norm condition number can be computed as $\kappa_2(A) = \lambda_{\max}(A) / \lambda_{\min}(A)$. Using the actual computed matrix, the extreme eigenvalues are approximately $\lambda_{\min} = 10.1083$ and $\lambda_{\max} = 387.5890$, and therefore $\kappa_2(A) = 38.3435$ \cite{golub2013matrix}.

\end{equation}
The algebraic accuracy of this solution is verified by the residual norm $\|Ax - b\|_2 \approx 9.0686 \times 10^{-15}$.

\subsection{Problem 2: Original Finite-Difference Formulation}

The original discrete problem was executed exactly as prescribed by Code 2 using the seed $318375$. This generated the parameters $k = 0.0847$, $f = 0.6000$, grid spacing $h=0.1$, and selected the Dirichlet--Dirichlet boundary condition corresponding to $T(0) = 0$ and $T(1) = 0$.

The resulting linear system $M_{orig} T_{orig} = s_{orig}$ was solved computationally. The numerical residual is $\|M_{orig} T_{orig} - s_{orig}\|_2 \approx 2.9899 \times 10^{-16}$. The computed solution satisfies the generated discrete linear system to near machine precision. However, this algebraic residual is fundamentally distinct from and does not imply consistency with the stated continuous PDE.

The assignment mathematically defines the steady-state heat equation as:
\begin{equation}
    -k T''(x) = f, \quad x \in (0, 1).
\end{equation}
The physical configuration of this boundary-value problem is illustrated in \autoref{fig:problem2-physical-configuration}.

\begin{figure}[ht]
    \centering
    \includegraphics[width=0.9\textwidth]{figures/problem2_physical_configuration.pdf}
    \caption{One-dimensional steady-state heat-conduction configuration for the generated Dirichlet--Dirichlet boundary conditions.}
    \label{fig:problem2-physical-configuration}
\end{figure}

Subject to the Dirichlet--Dirichlet boundary conditions, the exact analytical solution can be derived by integrating the constant source term twice:
\begin{equation} \label{eq:exact-solution}
    T_{exact}(x) = \frac{f}{2k} x (1 - x).
\end{equation}
Given $k, f > 0$, the analytical solution has specific qualitative properties: it is non-negative on $[0,1]$, strictly concave downward ($T''(x) = -f/k < 0$), reaches a global maximum at the center of the domain $x=0.5$ ($T_{exact}(0.5) \approx 0.8855$), and decreases to the fixed temperature at both boundaries.

A rigorous diagnosis reveals that the prescribed discrete formulation is not consistent with the continuous differential equation stated in the assignment. Specifically:
\begin{enumerate}
    \item \textbf{Sign inconsistency:} The interior matrix coefficients $(1/h^2, -2/h^2, 1/h^2)$ approximate the positive second derivative $T''_{i}$, omitting the required negative sign in the Laplacian operator.
    \item \textbf{Source scaling inconsistency:} The generated right-hand side is $s_i = (h^2/k) f$, which improperly scales the source by $h^2$. Together with the sign inconsistency, the interior nodes inadvertently model the equation $T'' = \frac{h^2}{k}f$.
\end{enumerate}
Consequently, at the prescribed grid resolution $h=0.1$, the original formulation produces a qualitatively different temperature profile. As shown in \autoref{tab:temperature-comparison}, its maximum absolute error relative to the analytical solution of the stated continuous problem is approximately $0.8944$. This discrepancy is attributable to the inconsistency of the discrete equations with the stated continuous model, rather than to failure of the linear solver.

\subsection{Problem 2: Corrected Formulation}

To construct a finite-difference system mathematically consistent with $-k T'' = f$, a corrected formulation was implemented. For the interior nodes ($1 \le i \le 9$), the standard central difference approximation was used:
\begin{equation}
    -\frac{1}{h^2} T_{i-1} + \frac{2}{h^2} T_{i} - \frac{1}{h^2} T_{i+1} = \frac{f}{k}.
\end{equation}
For the Dirichlet boundaries at $x=0$ and $x=1$, they are strictly enforced via:
\begin{equation}
    T_0 = 0 \quad \text{and} \quad T_{10} = 0.
\end{equation}
This yields a system that is an exact discrete representation of the continuum equation for quadratic solutions.

\subsection{Physical Interpretation}

The stated steady-state boundary-value problem describes a one-dimensional bar subject to a constant internal heat source $f > 0$. The homogeneous Dirichlet boundary conditions at $x=0$ and $x=1$ fix the edges to a baseline reference temperature of zero. Physically, thermal energy is continuously generated inside the domain and must flow outwards through both boundaries to dissipate. This mechanism produces a symmetric temperature profile that is concave downward and reaches its maximum exactly at the midpoint of the domain. The corrected numerical solution reproduces these qualitative features perfectly, matching the analytical profile at all grid points.

By contrast, the original algorithmic formulation uses a discrete operator with the sign of the positive second derivative, together with the nonstandard source scaling described above. At the prescribed grid, this produces a concave-up profile with temperatures below the reference value imposed at the boundaries. The negative profile is inconsistent with the analytical solution of the stated PDE under the specified parameters and boundary conditions. This behavior is a consequence of the inconsistency between the generated discrete system and the stated differential equation, not evidence of numerical instability in the linear solve.

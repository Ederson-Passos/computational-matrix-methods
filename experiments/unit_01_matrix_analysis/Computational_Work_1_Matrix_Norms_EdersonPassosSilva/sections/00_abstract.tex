\begin{abstract}
This computational work investigates matrix norms, singular value decomposition (SVD), matrix reconstruction, and low-rank approximation through two numerical experiments. First, for a pseudo-random matrix $A \in \mathbb{R}^{8\times16}$ with entries in ${-1,0,1}$, the induced $1$-, $2$-, and $\infty$-norms and the Frobenius norm are computed. The relationship between the induced $2$-norm and the largest singular value is then established, followed by the full SVD, reconstruction error analysis, and a rank-$4$ approximation. Second, SVD is applied to a $200\times200$ matrix representing a structured mathematical image. The singular-value spectrum and Frobenius reconstruction errors are used to examine the effect of rank truncation. The numerical results illustrate the connection between singular values, matrix norms, exact reconstruction, and low-rank representations, with the computations performed in Python using NumPy.
\end{abstract}
